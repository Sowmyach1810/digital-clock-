
# Digital Clock

## Project Overview
A simple digital clock built using HTML5, CSS3 and JavaScript.

## Features
- Displays current hours, minutes and seconds.
- Automatically updates every second.
- Uses leading zeros for single-digit values.
- Responsive design for mobile devices.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Used
- JavaScript Date object
- setInterval()
- DOM manipulation
- padStart()
